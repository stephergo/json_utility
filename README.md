# Data-Sync Library

A simple Python library to facilitate data synchronization between JSON files, Excel spreadsheets, and a local database (SQLite or DuckDB).

This library is designed to be simple, testable, portable, and maintainable.

## Core Features

- Load data from JSON or Excel.
- Save data to JSON or Excel.
- Synchronize data with a DuckDB/SQLite database.
- Provide a simple interface for data manipulation via Pandas DataFrames.
